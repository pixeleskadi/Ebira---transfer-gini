# Ebira source versions

Each version has its complete source folder and checksum/provenance manifest. Root source is based on candidate 4.

- [candidate-1](candidate-1/README.md): First native Windows/Android candidate
- [candidate-2](candidate-2/README.md): Windows layout and network-adapter selection fixes
- [candidate-3](candidate-3/README.md): Android local-only hotspot, laptop discovery and TLS connection reuse
- [candidate-4](candidate-4/README.md): Windows checked-device approval fix; Android remains candidate 3

Original PoC history remains in Git. Snapshot commits were imported now without inventing historical dates. The private pixeleskadi/ebira repository retains planning documents; this repository holds the app implementation. Installable builds are local deliverables, outside source control.
